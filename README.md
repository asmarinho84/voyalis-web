# Voyalis

Site gratuito de consulta de viagens: voos do mais barato ao mais caro, ofertas escondidas, hospedagem, atrações, segurança e custo de vida do destino, e o mapa dos destinos mais baratos para as suas datas.

- Página estática publicada pelo GitHub Pages. Sem login, sem cookies, sem anúncios, nenhum script de terceiros ao abrir.
- Preços consultados na hora (Google Flights, Google Hotéis e Google Maps, via SerpApi), com a chave gratuita de cada visitante, por um intermediário seguro (Cloudflare Worker) que não guarda chaves nem pesquisas.
- Contador de acessos anônimo (GoatCounter), sem cookies, desligado quando o navegador pede para não ser rastreado.
